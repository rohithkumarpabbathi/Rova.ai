# 🤖 Rova AI

Rova AI is a modern AI-powered voice assistant built with Google AI Studio. It enables natural conversations through voice and text with a clean, responsive interface.

✨ Features
* 🎙️ Voice & text interaction
* 🤖 AI-powered responses
* ⚡ Fast and responsive UI
* 📱 Mobile-friendly design
  
🛠️Tech Stack
* HTML
* CSS
* JavaScript
* Google AI Studio
* Gemini API

🚀 Getting Started

```bash
git clone https://github.com/rohithkumarpabbathi/Rova-AI.git
```

Open the project and follow the setup instructions to run it locally.
